# 动力电池实验室安全与储能系统设计 · 虚拟仿真实验平台（离线版）

基于 three.js 的纯前端虚拟仿真教学平台，全部资源已内联，**无 CDN、无外部请求、无需联网、无需安装**。双击 `index.html` 即可使用。

## 包含内容

| 文件 | 说明 |
|---|---|
| `index.html` | 平台门户：5 个实验卡片 + 3 个认知模块 + 环境自检 |
| `exp01.html` | 实验 01 单体性能测试与危化品安全操作（22 步 + 三维实验室 + 物理仿真 + 评分报告） |
| `exp02.html` | 实验 02 热失控特性与热管理安全（3D 电池包可视化沙盘 · 虚拟防护试验舱） |
| `exp03.html` | 实验 03 BMS 算法仿真与 AI 安全诊断（SOC 估计 · 故障注入 · AI 评测 · 热成像） |
| `exp04.html` | 实验 04 高压系统与特种设备集成（预充 · 保护协调 · 绝缘监测 · LOTO） |
| `exp05.html` | 实验 05 梯次利用与回收危化品处置（老化评估 · 分级分组 · 回收处置） |
| `param.html` | 参数库：116 条参数 × 8 个域，含来源 / 版本 / 核验状态与跨实验一致性校验 |
| `archive.html` | 实验档案：本机存档汇总、操作时间线、评分与 JSON/CSV/报告导出 |
| `battery-pack-3d.html` | 整包数字孪生（CTP 无模组 · 12 层拆解 + 整车底盘 + 引线标注 + 采样域聚焦 + X 光 + 电路拓扑） |

合计约 6.3 MB。

## 怎么用

1. 把整个文件夹拷到任意位置（U 盘、教室机房、自己的电脑都行）；
2. 双击 `index.html`（或 `start.bat`）进入平台门户；
3. 点实验卡片，即在门户页内展开该实验。

> 文件夹内所有 HTML 必须放在一起。单独打开 `index.html` 也能用，但「在新窗口打开」需要对应文件在旁。

## 特点

- 键盘 `1–5` 可直接打开对应实验
- 实验 01 报告页支持导出 CSV、打印为 PDF
- 平台不上传任何数据，全部计算在本机完成
- 成绩存在浏览器本地存储，换浏览器 / 隐私模式会读不到，属正常现象

## 常见问题

- **三维区域空白**：门户顶部「环境自检」可查看 WebGL 状态；若不可用，在浏览器设置中开启「使用硬件加速」后重启浏览器。即使三维不可用，实验流程与数据仍能正常完成。
- **分发给同学**：把整个文件夹打包成 zip 发送，不要只发单个 HTML。
